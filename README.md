# Biblioteca Digital UniFECAF

Primeira interface web da biblioteca digital, feita só com HTML e CSS.

## Estrutura
- `index.html`: conteúdo da página
- `css/style.css`: layout, identidade visual e responsividade
- `assets/imagens/`: capas, ícones, favicon e ilustração (SVG)

## Como abrir
Abra o `index.html` no navegador. Não precisa instalar nada.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `biblioteca-unifecaf` e envie os arquivos.
2. Em Settings > Pages, escolha Branch `main` e pasta `/ (root)`.
3. O link aparece em alguns minutos: `https://SEU-USUARIO.github.io/biblioteca-unifecaf/`
