# 📚 Biblioteca Digital UniFECAF

> Interface web moderna, responsiva e acessível desenvolvida para a disciplina **Design Web** da UniFECAF.

## 📖 Sobre o projeto

A **Biblioteca Digital UniFECAF** é uma interface web desenvolvida com o objetivo de proporcionar uma experiência simples, intuitiva e agradável para estudantes que desejam visualizar livros, explorar categorias, conhecer conteúdos em destaque e consultar os serviços oferecidos pela biblioteca.

O projeto representa a transformação de um protótipo de baixa fidelidade em uma interface web estruturada, responsiva e alinhada à identidade visual da instituição.

O desenvolvimento foi realizado utilizando **HTML5 e CSS3**, priorizando organização, semântica, responsividade, acessibilidade e consistência visual.

---

## 🎯 Objetivos

O projeto tem como principais objetivos:

* Desenvolver uma interface moderna para uma biblioteca digital acadêmica;
* Facilitar a navegação e descoberta de conteúdos;
* Organizar visualmente livros, categorias e serviços;
* Aplicar princípios de hierarquia visual e design de interfaces;
* Desenvolver uma experiência adaptável a diferentes tamanhos de tela;
* Aplicar boas práticas de HTML semântico e CSS;
* Implementar princípios básicos de acessibilidade;
* Transformar um protótipo de baixa fidelidade em uma interface funcional.

---

## ✨ Principais características

### 🏠 Interface institucional

Layout desenvolvido considerando a identidade visual da UniFECAF, com foco em clareza, organização e consistência entre as diferentes seções.

### 📚 Catálogo de livros

Apresentação visual dos livros disponíveis, permitindo uma identificação rápida de títulos e informações relevantes.

### 🗂️ Categorias

Organização dos conteúdos por categorias para facilitar a navegação e descoberta de materiais.

### ⭐ Destaques

Seção destinada à apresentação de conteúdos em destaque dentro da biblioteca.

### 🛎️ Serviços

Área dedicada à apresentação dos principais serviços oferecidos pela biblioteca.

### 📱 Design responsivo

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, incluindo:

* Computadores;
* Notebooks;
* Tablets;
* Smartphones.

### ♿ Acessibilidade

Foram consideradas boas práticas de acessibilidade, incluindo:

* HTML semântico;
* hierarquia adequada de títulos;
* textos alternativos para imagens;
* navegação por teclado;
* estados de foco;
* contraste e legibilidade;
* suporte à preferência de redução de movimento.

## 🎨 Design e interface

O desenvolvimento visual buscou estabelecer uma identidade consistente entre todas as áreas da página.

Foram considerados aspectos como:

* Hierarquia visual;
* Tipografia;
* Espaçamento;
* Contraste;
* Cores institucionais;
* Organização dos conteúdos;
* Proporção dos elementos;
* Consistência entre componentes;
* Experiência em diferentes dispositivos.

A interface foi construída buscando equilibrar **estética, usabilidade e legibilidade**, evitando elementos visuais desnecessários que possam prejudicar a experiência do usuário.

---

## 📱 Responsividade

A interface utiliza uma abordagem responsiva para adaptar o conteúdo conforme o espaço disponível.

Entre as estratégias utilizadas estão:

* CSS Grid;
* Flexbox;
* Media Queries;
* Unidades relativas;
* Tipografia fluida;
* `clamp()`;
* containers com largura máxima;
* imagens responsivas;
* reorganização dos componentes em telas menores.

O objetivo é evitar:

* Rolagem horizontal desnecessária;
* Sobreposição de elementos;
* Textos cortados;
* Imagens distorcidas;
* Botões inacessíveis;
* Quebras de layout.

---

## ♿ Acessibilidade

O projeto considera princípios básicos de acessibilidade para tornar a interface mais inclusiva.

Entre as práticas utilizadas estão:

* Estrutura HTML semântica;
* Hierarquia lógica de headings;
* Textos alternativos em imagens;
* Navegação por teclado;
* Indicadores visuais de foco;
* Uso adequado de elementos interativos;
* Contraste e legibilidade;
* Respeito à preferência `prefers-reduced-motion`.
